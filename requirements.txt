# Installs this project (and, through pyproject.toml, streamlit + duckdb).
#
# Editable on purpose. A plain "." copies the package into site-packages
# and leaves research/agent3_knowledge_base.json behind -- it is not
# packaged -- so the knowledge base loader cannot find it and every search
# fails at runtime. Editable keeps the installed package pointing at this
# checkout, where research/ is present. Do not "tidy" this back to "."
# without first making the knowledge base importable package data.
-e .
